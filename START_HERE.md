# Start here
1. Open this exact ModelScope folder in VS Code.
2. Follow README.md: create `.venv`, install `requirements.txt`, build `frontend/`.
3. Run `python -m pytest -q` yourself and compare with docs/COMPLETION_REPORT.md.
4. Read docs/MODELSCOPE_MASTER_GUIDE.md sections A–E, then the code in the
   order given in section K.
5. Download the data (`python scripts/download_data.py`) and start `.\run.ps1`.
   The completed official study is already in `artifacts/` on this machine; on
   a fresh machine, run a development study from the dashboard.
6. Make the review decision for the official study yourself (Review
   workspace). Nobody has done that yet.
7. Work through the exercises in section Q and record what you did in
   docs/MY_CONTRIBUTION.md.

The platform was implemented with AI assistance (see guide section R). Green
tests and a completed experiment are evidence about this prototype on this
dataset, not about real-world credit decisions.
